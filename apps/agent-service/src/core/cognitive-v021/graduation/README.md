# Graduation

Her predictions meet what happened. The Host compares only what a receipt can decide, and calibration is hers to admit.

Prediction metadata belongs to `../growth/expectations.ts`. `observations.ts` never adjudicates. `adjudications.ts` accepts explicit typed comparisons, later Thought checks, and Owner confirmation. Both layers are append-only. The latest adjudication by time, then insertion order, supplies calibration evidence.

`recorders.ts` contains exactly two automatic comparators: admitted Owner replies and complete speech delivery receipts. Each writes an observation, an explicit deterministic adjudication, and its idempotency key in one savepoint. Admission and terminal speech reconciliation call them. The existing reconciliation sweep services horizons. Recorder failure rolls back graduation writes without changing admission or delivery. Only identifiers, typed booleans, classification, and timestamps are copied; message text is never copied.

`calibration.ts` proposes bounded class adjustments from determinate outcomes. A later admitted Thought pass may admit or decline up to three proposals. Eligible lines are bounded to five. Superseded or forgotten basis evidence is ineligible. Rollback preserves history and removes eligible influence.

The sidecar mode defaults to `observe`. `observe` and `dark_apply` provide no graduation fields to Thought; dark mode counts what would have been shown. Only the authenticated Owner mode endpoint can select `apply`. Production activation requires separate Owner action.

Owner diagnostics and controls are registered in `server.ts`; mutation routes also require the transport Owner actor. The legacy diagnostic URL reads this sidecar implementation. Historical nuclear DDL belongs to `../../cognition/` and has no runtime graduation consumer. The nuclear retirement migration refuses any populated legacy C4 table before dropping anything.
