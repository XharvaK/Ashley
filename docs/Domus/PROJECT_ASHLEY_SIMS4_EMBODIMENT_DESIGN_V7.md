## 2. Executive architectural result

1. **One Ashley survives intact.** The Sim remains a body/world surface;
   any System One model remains a Host-side typed-inference utility that owns
   nothing. No rename of frozen authority concepts was needed; the only
   naming adjudication is §8: keep the historical path-kind names
   `J-RANK` / `J-MEMBERSHIP` (frozen labels, provider-neutral contract text)
   rather than renaming to `S1-*`, because renaming frozen concepts adds
   confusion without evidence.
2. **Current Ashley already contains nearly everything V6.1.1 asked
   Targeted-Source questions about.** TS1/TS2/TS3/TS5 close against `60fec11`
   as concrete reuse maps (§21); TS4 reframes and broadens beyond TypeSafe
   (§5.4). No embodiment-specific identity ledger, recovery orchestrator,
   event bus, pursuit engine, planner, privacy system, or memory architecture
   is justified. V7 deletes those temptations explicitly (§16).
3. **The old "same-box Windows A1–A4" topology assumption is retired.**
   Ashley production lives on the Mint host; Sims runs on Owner Windows.
   V7 adopts: **Mint authority + Windows-local Phase A harness + one narrow
   bridge** (§16). The bridge carries already-authorized deterministic
   commands one way and observations/receipts back; it is never a second
   brain, never carries Thought deliberation, and its necessity arrives at
   A0 (not A6) — the single largest structural delta from V6 (V7-02).
4. **Patch 1.128.90.1030 is autonomy-significant but control-neutral.**
   Preference-gated autonomy, duplicate-push suppression, and the new
   `cancel_on_user_directed_action` tuning field make the A3 envelope more
   observable and release/cleanup easier to witness — but grant zero
   decision-hold control and change nothing about body binding, the action
   ladder, or Sofa A preference (§7).
5. **System One is now a field, not a vendor.** Jev remains a legitimate
   hosted candidate with the best independent calibration evidence on
   classification-shaped tasks; Laya and Kev-0.8B (plus Von as third) form a
   credible local-light shadow shortlist; Nimble-9B is disqualified for the
   same-PC lane on weight size alone; Tev1 is a baseline-grade DIY classifier,
   not a System One runtime (§20). No provider is locked; silent fallback is
   rejected as law (§11).
6. **Same-PC inference while Sims runs is source-feasible and unproven.**
   Encoder-class models (~0.3–0.8B) fit the RTX 2080 Super 8 GB / 32 GB RAM
   budget on paper with headroom to spare, preferably on CPU or in a
   separate process — but VRAM-under-load, spike, and contention numbers do
   not exist without measurement. V7 records `NEEDS_LOCAL_BENCHMARK`, not
   confidence (§8.4, §20D).
7. **Hosted inference is cheap per decision and expensive per tick.**
   At ~1–2K tokens per decision and $0.042/1M input, one decision costs
   ~$0.00004–0.00008: hundreds of event-driven decisions per day cost cents,
   while naive 1/5/10-Hz polling costs ~$5/$27/$54 per day. The architecture
   therefore stays event-driven — typed inference only where deterministic
   truth is insufficient — and cost never justifies per-tick calling (§8.5).
8. **Next step is one Owner decision,** not engineering: accept V7 as master,
   then separately authorize (or decline) Phase A. Nothing in V7 starts A0.
