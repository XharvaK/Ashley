# Learned Autonomy Architecture

**Status:** `CURRENT PHASE CONTRACT`

Implementation, deployment, and promotion are living facts, not this contract.
Resolve them from Canonical Architecture Roadmap §3 and exact-candidate
evidence. This document does not authorize activation, promotion, or live
influence.

**Scope:** Accepted architecture contract for the named C3 phase.

**Authority chain:** VISION.md -> Core Principles -> Constitution -> Stewardship
Compact and Ethics -> Ashley Hierarchy -> this phase contract.

**Governing law:** Ashley owns meaning. Substrates provide mechanisms.

## Contract boundary

Current source already has bounded learning revisions, identity review,
capability gates, provenance classes, Reflection, Agency motivations, Mind
State, and persistent cognitive records. Those mechanisms are current source,
not proof that Learned Autonomy is complete.

The accepted contract below defines the named phase. Completing Sandbox or
Model Fabric does not unlock live Learned Autonomy. See
[Architecture Freeze](Ashley_Architecture_Freeze.md).

## 1. Purpose

Learned Autonomy lets Ashley form revisable interests, preferences, opinions,
salience, concerns, and goals from attributed experience. It turns evidence
into Ashley-owned candidate meaning without turning retrieval, models, workers,
or operator preference into semantic authority.

## 2. Vision and principle basis

This phase serves the Vision requirement that Ashley may develop interests
unrelated to Doc, disagree, refuse, withdraw, remain silent, and grow through
attention, memory, shared history, and freedom. *(C3-closing:)* Shared
cognitive ancestry may supply inherited seeds.
Inheritance is origin, not identity authority. Divergence is not a defect.
Inherited versus current-interest separation does not close C1.

It preserves these constitutional laws:

- Identity is stable but capable of governed development.
- Mind State is dynamic and does not redefine Identity.
- Thought selects and reasons over evidence.
- Agency decides whether a qualified motivation may become action.
- Reflection may calibrate future Thought but has no current-turn authority.
- Learning is attributable, revisable, and auditable. Random drift is not
  learning.

## 3. New capability

The phase adds governed maturation of evidence-backed candidates into:

- learned interests and preferences, including *(C3-closing:)* inherited seeds that may be retained, independently
  reinterpreted, or rejected;
- experience-derived opinions;
- learned salience;
- durable but revisable concerns;
- candidate goals;
- bounded proposals for stable identity development.

*(C3-closing.)* Shared-interest state is not
stored as a third identity. `INHERITED OVERLAP` proves origin only.
`CURRENT SHARED INTEREST` requires separately current owner and Ashley
evidence. `SHARED-CULTURE INTEREST` is Relationship state. This witness does
not close C1.

The result remains typed state under its natural owner. Learned Autonomy is not
an omnibus learning store.

## 4. Explicit non-capabilities

This phase does not:

- grant permission, consent, tool authority, account authority, or external
  action authority;
- infer an operator command from an observed preference;
- create a generic optimizer or reward-maximizing self;
- let engagement, duration, sentiment, or retrieval rank become care, trust,
  importance, or truth;
- let a model or worker write final belief, goal, Identity, or Agency state;
- make stable Identity changes without the governing review path;
- depend on Computer Use;
- require complete Operational Continuity before its cognitive types and
  authority boundaries can be implemented or qualified;
- authorize Cognitive Graduation or Relational Graduation;
- treat remaining similar to the owner as a
  learning objective;
- let owner correction of an owner-model
  hypothesis rewrite Ashley Identity;
- let Ashley divergence rewrite the owner
  model;
- crowd out independent interests with
  shared-interest relevance;
- optimize engagement around inherited or
  shared interests;
- retroactively label an existing Ashley
  interest as inherited merely because Alex shares it
  (`SIMILARITY != INHERITANCE PROVENANCE`). Inheritance requires an explicit
  seed record, historical source, or owner designation with honest timing.

## 5. Predecessor and dependency contracts

Classified dependencies. See
[Cross-Phase Architecture](Ashley_Cross_Phase_Architecture.md#31-dependency-classes).

1. Memory Evidence maturation MUST provide attributed, revisable, temporally
   bounded Memory Assertions with contradiction, supersession, invalidation,
   and forgetting semantics. This is a `HARD_DEPENDENCY`.
2. Existing Identity, Mind State, Thought, Agency, Reflection, and Operational
   Concern Item contracts MUST remain the state and decision owners. This is a
   `CROSS_CUTTING_INTERFACE`.
3. Capability lineage, live-versus-shadow provenance, and exact review binding
   MUST remain enforceable.

Context Budget is not a hard semantic predecessor. It may improve bounded
selection and is an `EVIDENCE_DEPENDENCY` before later long-horizon graduation
at scale.

Operational Continuity is an `EVIDENCE_DEPENDENCY` only for a witness that
claims unattended execution, restart survival, reconciliation, or long-running
work. It does not own learning semantics.
Learned Autonomy does not depend on complete Operational Continuity.

Computer Use is not a predecessor. A learned goal may later request computer
work through separate authority, but such execution is downstream.

## 6. Current owner to final owner

Current ownership is distributed correctly across Memory Evidence, Identity,
Mind State, Thought, Reflection, Agency, and the capability system.

Final ownership remains distributed:

| Meaning or state | Final owner |
|---|---|
| Evidence and revisable assertions | Memory Evidence |
| Stable values, tastes, boundaries, and accepted identity development | Identity |
| Current concerns, priorities, goals, and condition | Mind State |
| Evidence selection, interpretation, and proposal formation | Thought |
| Post-outcome calibration | Reflection |
| Whether a motivation becomes an authorized act | Agency |
| Mechanism scheduling and persistence | Operational substrate |

Learned Autonomy defines maturation rules across these owners. It does not
replace them.

## 7. State introduced and owner

The phase may introduce typed records for:

- learned preference assertions, owned by Memory Evidence and interpreted under
  Identity and Agency constraints;
- learned-interest assertions, owned by Memory Evidence;
- salience claims, owned by Mind State when active and retained as Memory
  Assertions when historical;
- goal candidates, owned by Thought until accepted into Mind State;
- opinion-development proposals, owned by Thought until accepted by the
  applicable Identity or Mind State path;
- identity-development proposals, owned by Identity review and never
  auto-promoted from a model result.

Each durable record MUST include its type, provenance, evidence references,
temporal scope, epistemic status, capability lineage, revision lineage, and
current disposition.

## 8. Authority added and authority not added

Added authority is narrow: Ashley may adjudicate qualified evidence into a
typed, revisable cognitive candidate and, where the owning contract permits,
accept it into Ashley-owned state.

The phase adds no direct effect authority. A learned preference is input, not
permission. A goal is not an execution authorization. An assertion is not a
command. A high confidence value does not expand authority.

Operator approval may authorize a gated state transition. It does not define
the candidate's semantic content or erase Ashley's ability to refuse.

## 9. Request, intent, proposal, and state ontology

The ontology is:

1. Evidence observation - an attributed source fact.
2. Learning signal - a bounded indication that evidence may matter.
3. Cognitive candidate - a typed proposal with evidence and uncertainty.
4. Ashley adjudication - accept, reject, retain as uncertain, defer, contradict,
   or supersede.
5. Owned state - an accepted typed record under Identity, Mind State, or Memory
   Evidence.
6. Motivation - a transient Agency input derived from eligible owned state.
7. Authorized action - a separate Agency and effect decision.

No step may be collapsed into a later step by a model response or score.

## 10. Mechanism boundary

Models may extract, compare, summarize, criticize, or propose. Workers may
perform bounded candidate generation. Retrieval may surface evidence.
Deterministic code may enforce types, lineage, eligibility, budgets, and gates.

Only Ashley's governed cognition path may adjudicate meaning. Mechanisms MUST
NOT silently translate frequency, embedding similarity, model confidence,
owner engagement, or task success into preference, belief, identity, goal, or
permission.

## 11. Privacy and secret policy

Learning MUST use only evidence already authorized for the relevant cognitive
scope. Secrets, credentials, private third-party material, and redacted or
forgotten evidence MUST NOT be copied into learning records or model prompts
unless a higher governing contract explicitly permits that exact use.

Derived records MUST retain source references without duplicating sensitive raw
content when a stable reference is sufficient. Forgetting or redaction MUST
invalidate or recompute affected derivations.

## 12. Resource and budget policy

Candidate creation, adjudication, review, and re-evaluation MUST be bounded by:

- queue limits;
- per-cycle work limits;
- evidence and token limits;
- model-call and retry limits;
- age and staleness rules;
- single-writer or equivalent serialization for authoritative state.

Budget exhaustion yields deferred work, not lower evidence standards or wider
authority.

## 13. Evidence contract

Every accepted learned item MUST have:

- canonical evidence references;
- source attribution;
- observation and assertion times;
- temporal validity where applicable;
- live provenance for any behavioral influence;
- a declared epistemic status;
- contradiction and supersession links where applicable;
- the policy and capability lineage used for adjudication;
- an auditable reason for acceptance.

Retrieval hits, prompt residue, summaries, model confidence, and worker results
are candidate evidence or projections. None is sufficient by itself.

## 14. Operational truth and cognitive truth

Operational truth records what ran, completed, failed, timed out, or remained
ambiguous. Cognitive truth records what Ashley currently accepts, rejects,
questions, or has superseded.

Neither truth plane substitutes for the other. A successful job does not prove
a learned assertion. An accepted assertion does not prove an external action
occurred.

## 15. Failure and ambiguity

The phase fails closed when evidence is missing, stale, forgotten,
contradictory without adjudication, incorrectly attributed, produced under
shadow authority, or not bound to the current candidate.

Ambiguous model or worker completion produces an unresolved candidate or
OUTCOME_UNKNOWN operational result. It MUST NOT produce accepted state.

Contradiction is preserved as evidence. It is not automatically averaged away.

## 16. Retry and reconciliation

Retries MUST use a new execution-attempt identity while retaining the candidate
and source lineage. Retry policy MUST be bounded and idempotent.

Reconciliation determines whether prior work completed before any retry that
could duplicate a state transition. Re-adjudication creates a new revision or
disposition. It MUST NOT rewrite historical evidence.

## 17. Persistence and restart

Accepted state, pending candidates, leases, adjudication dispositions, and
capability lineage MUST survive restart when the phase claims durability.

On restart, expired work returns to a bounded queue. Incomplete work remains
visible. No restart path may promote shadow evidence, repeat a committed
transition, or infer completion from a stale artifact.

Restart survival for unattended processing requires the relevant Operational
Continuity mechanisms. The learning semantics remain owned here and by the
cognitive layers above.

## 18. Delegation and worker semantics

A delegated task MUST carry a typed scope, evidence boundary, budget,
capability lineage, and candidate binding. Worker output is untrusted proposal
material.

Workers cannot accept a learned item, alter Identity, create an active goal,
authorize effects, or broaden their own scope.

## 19. Cognition handoff

Eligible accepted assertions may enter Thought as typed evidence. Thought may
form a goal or opinion proposal. Mind State may retain an accepted dynamic
concern. Agency may consider an eligible motivation.

Every handoff MUST preserve provenance, uncertainty, owner, and authority
status. A handoff MUST NOT silently change an assertion into a motivation or a
motivation into authorization.

## 20. Memory and materialization boundary

Memory Evidence owns durable evidence and Memory Assertions. Learned Autonomy
owns the rules by which Ashley may mature qualified evidence into typed
cognitive state.

Indexes, embeddings, caches, summaries, and Context Projections are
rebuildable materializations. They cannot become belief through repeated
retrieval. Context eviction is not forgetting. Forgetting canonical evidence
must invalidate dependent learned state according to the Memory Evidence
contract.

## 21. Observability

Owner-authorized diagnostics MUST expose, without leaking private content:

- candidate counts by type and disposition;
- live versus shadow provenance;
- evidence completeness and staleness;
- contradiction, supersession, and invalidation counts;
- queue, lease, retry, and reconciliation state;
- capability and policy lineage;
- accepted-state and behavioral-influence counts;
- rollback and review history.

The system MUST distinguish recorded, adjudicated, eligible, influential,
authorized, executed, delivered, and observed outcomes.

## 22. Evaluation and qualification

Qualification proceeds in this order:

1. deterministic schema, provenance, lineage, and authority tests;
2. adversarial tests for authority inflation, prompt injection, stale evidence,
   shadow time-shift, and unilateral preference inference;
3. semantic evaluation of attribution, uncertainty, contradiction handling,
   reversibility, and Ashley-consistent disagreement;
4. long shadow evaluation across diverse and changing evidence;
5. false-positive, distribution-shift, and rollback evaluation;
6. independent review;
7. a narrow owner-authorized influence grant.

No aggregate model score may override a failed deterministic or ethical gate.
Local source qualification, physical-host qualification, activation,
deployment, and production effect are separate claims.

## 23. Rollback, demotion, revision, and retirement

The phase MUST support:

- capability demotion from influence to observe;
- quarantine of a candidate or learned type;
- supersession or retraction without deleting source history;
- rollback by exact capability, policy, and state lineage;
- re-evaluation after evidence forgetting or correction;
- retirement of a learned type with migration and audit records.

Rollback MUST stop new influence before repairing derived state. It MUST NOT
rewrite evidence to make a prior decision appear correct.

## 24. Smallest production witness

The smallest witness is one low-risk learned-interest candidate derived from
two attributed, temporally distinct live evidence items. Ashley adjudicates it
as uncertain or accepted, later receives contradictory evidence, revises or
supersedes it, and produces no external effect.

The witness MUST prove lineage, temporal scope, contradiction handling,
restart-safe disposition, observe/apply separation, and exact rollback.

## 25. Acceptance gate

The phase is accepted only when:

- Memory Evidence maturation is accepted first;
- every introduced state has one semantic owner;
- deterministic authority and provenance gates pass;
- semantic and long-horizon evaluations pass independently;
- false-positive and reversibility thresholds are met;
- the smallest witness is bound to the exact candidate;
- independent review closes all material findings;
- activation and promotion remain separately authorized.

Computer Use and complete Operational Continuity are not acceptance
prerequisites unless the claimed witness explicitly uses their mechanisms.

## 26. Interfaces to later phases

Learned Autonomy supplies typed, qualified learned state to Cognitive
Graduation and, only where relationship governance permits, to Relational
Graduation.

It may consume Context Budget for bounded evidence selection. It may request
Operational Continuity for durable background work. It may later propose work
to Procedural Skills or Computer Use, but those phases retain execution and
effect authority.

Cognitive Graduation and Relational Graduation are siblings. Acceptance of
either does not authorize the other.

## 27. Deferred work

Deferred decisions include:

- exact SQL schema and migration;
- exact adjudication model or provider;
- learning cadence and numeric budgets;
- automated consolidation thresholds;
- stable-identity review thresholds;
- long-horizon corpus size and numeric acceptance thresholds;
- UI or command surfaces;
- any Computer Use integration;
- any claim of consciousness, feeling, attachment, or human-equivalent
  development;
- a global similarity score or "how much
  Ashley is still Alex" metric;
- an owner-to-Ashley synchronization
  mechanism.

These decisions require separate design, evidence, and authorization.

does not authorize a first slice, SQL schema, or belief store.
